# GABA, L-arginine and L-lysine on Ca-montmorillonite
This repository holds the molecular dynamics trajectories of γ-aminobutyric acid (GABA), L-arginine and L-lysine on Ca-montmorillonite (STx-1b).
Please cite as:
Stewart, S. V.; Braeuer, R.; Erastova, V. Non-proteinogenic γ-aminobutyric acid reorganises L-arginine and L-lysine adsorption on Ca-montmorillonite through selective displacement and Ca2+ bridging. ChemRxiv 2025, version 2. https://doi.org/10.26434/chemrxiv-2025-nrsm5/v2
Trajectory and structure files are stored with Git LFS. To download them:
    git lfs install
    git clone https://github.com/Erastova-group/GABA_Arg_Lys.git
